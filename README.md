One warning label for a time machine, written to be the funniest — 97 characters, one line, delivered with a straight face:

> WARNING: Do not meet yourself in the past. The last passenger who did is now his own grandfather.

The joke turns a real hazard of time travel, the grandfather paradox, into the punchline and saves the surprise for the last few words: meet your past self and you come home as your own grandfather. A small Python program carries the label in its code and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

This writes the label to `/output/entry.txt` (1–120 characters, UTF-8, single line).
